# 🎨 Transfert de Couleur par Transport Optimal
*Color Transfer via Optimal Transport*

🌍 **[English version below](#english-version)**

## 🇫🇷 Version Française

### 📝 Contexte et Objectif
Ce projet d'apprentissage a été réalisé pour explorer le domaine du traitement d'images en implémentant une méthode algorithmique de "Transfert de couleur". 
L'objectif est de capturer la distribution des couleurs d'une image de référence (l'image "Cible") et de l'appliquer sur le contenu structurel d'une autre image (l'image "Source"), tout en conservant la géométrie et les détails de cette dernière.

Pour y parvenir, ce travail s'appuie sur les concepts et le cadre mathématique du **Transport Optimal**.

### 🛠️ Outils et Technologies
* **Langage & Environnement :** Python, Jupyter Notebook
* **Domaines d'application :** Traitement d'images (Computer Vision), Mathématiques appliquées
* **Bibliothèques principales :** `NumPy` (calcul matriciel), `OpenCV` (traitement d'images), `Matplotlib` (visualisations 2D et 3D)

### 📂 Contenu du dépôt
* `SITTI-MAWUBEJRO.ipynb` : Le notebook Jupyter principal documentant l'implémentation de l'algorithme, les étapes de traitement (extraction des canaux RGB) et les visualisations des résultats.

> ⚠️ **Note de traçabilité :** Les images utilisées initialement pour tester l'algorithme (ex: `parcfloral.png`, `parrot.png`) ne sont pas incluses dans ce dépôt. Le notebook est partagé à des fins de documentation de la démarche technique et algorithmique.

## 🇬🇧 English Version

### 📝 Context and Objective
This learning project was developed to explore the field of image processing by implementing a "Color Transfer" algorithm. 
The goal is to capture the color distribution of a reference image (the "Target Image") and apply it to the structural content of another image (the "Source Image"), while preserving the latter's details and geometry.

To achieve this, the work relies on the concepts and mathematical framework of **Optimal Transport**.

### 🛠️ Tools & Technologies
* **Language & Environment:** Python, Jupyter Notebook
* **Application Domains:** Image Processing (Computer Vision), Applied Mathematics
* **Core Libraries:** `NumPy` (matrix computation), `OpenCV` (image processing), `Matplotlib` (2D and 3D visualizations)

### 📂 Repository Content
* `SITTI-MAWUBEJRO.ipynb`: The main Jupyter notebook documenting the algorithm implementation, processing steps (RGB channel extraction), and result visualizations.

> ⚠️ **Traceability Note:** The original images used to test the algorithm (e.g., `parcfloral.png`, `parrot.png`) are not included in this repository. The notebook is shared for the purpose of documenting the technical and algorithmic approach.
